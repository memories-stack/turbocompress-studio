# คู่มือการใช้งานและอธิบายเครื่องมือ — ZCut PRO `v2.4.0`

**ZCut PRO** คือโปรแกรมตัดต่อและแต่งสีวิดีโอแนวตั้ง `9:16` แบบ **Batch ความเร็วสูง (Apple Silicon GPU)** ทำงาน **ออฟไลน์ 100%** ไม่มีลายน้ำ และไม่มีค่ารายเดือน ออกแบบมาโดยเฉพาะสำหรับช่างภาพงานวิ่ง อีเวนต์ กีฬา และครีเอเตอร์ที่ต้องจัดการคลิปจากกล้องโปร (Nikon, Sony, Canon, Fujifilm, DJI, iPhone ฯลฯ) ทีละหลายสิบถึงหลายร้อยคลิป

---

## 1. ภาพรวมหน้าจอการทำงาน (4 โซนหลัก)

- **Topbar (ด้านบน):** แสดงสถานะชิป GPU, โฟลเดอร์ปลายทาง (คลิกเพื่อเปิดใน Finder), สลับโหมด **Dark / Light**, ปุ่ม **Face Search** (ค้นหาใบหน้านักวิ่งในวิดีโอ), **Clear Cache & RAM**, และปุ่มเช็กอัปเดต **OTA (`v2.4.0`)**
- **Media Pool (ฝั่งซ้าย):** แสดงคลิปเป็นตาราง **4 คอลัมน์** หรือแบบรายชื่อ (`List`), รองรับ `Import Folder`, `Select Files`, `Select All` และค้นหาชื่อไฟล์
- **Monitor 9:16 (ตรงกลาง):** แสดงพรีวิวคมระดับ **Retina `1440px`** ขอบเหลี่ยม `90°` ตรงตามต้นฉบับ พร้อมโหมดเทียบภาพ `Result | Split Wipe | 2-Up | Bypass` และเส้นไกด์ `Guides`
- **Inspector (ฝั่งขวา):** แบ่งเป็น 4 แท็บหลัก **`Transform` | `Edit` | `Color` | `Deliver`** และกล่องปุ่ม **Export All Clips (Vertical 9:16)** ปักหมุดด้านล่าง

---

## 2. ขั้นตอนการทำงานมาตรฐาน (5-Step Pro Workflow)

1. **Import คลิป:** กด `Import Folder` เลือกโฟลเดอร์จากการ์ดกล้อง (รองรับ 12+ แบรนด์ อ่าน EXIF เร็ว `4 ms/คลิป`)
2. **คัดคลิปเสีย & ตัดช็อตเด็ด (แท็บ `Edit`):** สแกนคัดคลิปเบลอทั้งคลิป, ตัดหัวคลิปเบลอ 1–5 วิแรก หรือให้ **AI Highlight Cutter** หาช่วงที่หน้าคมที่สุด
3. **จัดเฟรม & สโลว์โมชัน (แท็บ `Transform`):** ตั้ง `Fit / Fill`, ครอป, หรือปรับ `Speed 50%` + **`AI Smooth 50fps / 60fps`**
4. **แต่งสี & ผิวเนียน (แท็บ `Color`):** กด **`Smart Tone (AI Face)`** หรือเลือกโทนใน **`AI Filter Studio`** (6 Pro LUTs / ดูดสีจากรูปต้นแบบ / ผิวเนียน `Face AI`)
5. **Batch Export (แท็บ `Deliver` + ปุ่มสีน้ำเงิน):** เลือกความละเอียด (`1080×1920` / `4K`), บิตเรต, ตั้งชื่อไฟล์ แล้วกด **Export All Clips** (รันพร้อมกันหลาย Worker ด้วย Apple VideoToolbox)

---

## 3. อธิบายเครื่องมือละเอียดครบทั้ง 4 แท็บ

### แท็บที่ 1: `Edit` (AI คัดคลิปและตัดต่ออัตโนมัติ)

| เครื่องมือ | หน้าที่การทำงาน | วิธีใช้งานแนะนำ |
| :--- | :--- | :--- |
| **AI ตัดช็อตเบลอ 1–5 วิแรก** | ตรวจจับจังหวะยกกล้องหรือโฟกัสยังวืดช่วงต้นคลิป แล้วตั้งจุดตัดเริ่ม (`trim_start`) ให้อัตโนมัติ | กด `สแกนทุกคลิป` เพื่อให้ทุกคลิปเริ่มที่เฟรมคมกริบ |
| **AI คัดภาพเบลอทั้งคลิป** | สแกนหาคลิปที่หลุดโฟกัสทั้งคลิปและติ๊กออก (`Mark Rejected`) ไม่ให้เสียเวลา Export | เลือกระดับ `สมดุล (แนะนำ)` แล้วกด `คัดคลิปเบลอทั้งภาพ` |
| **AI Highlight Cutter (ตัดช็อตเด็ด)** *(ใหม่ v2.4.0)* | ใช้ **Apple Vision (`VNDetectFaceCaptureQuality`) + Sharpness** หาช่วงที่ใบหน้าและภาพคมชัดที่สุดในคลิป | 1. คลิกเลือกความยาว **`3s / 4s / 5s / 7s / 9s / Custom (1.5–60s)`**<br>2. กด `สแกนคลิปนี้` หรือ `สแกนทุกคลิป`<br>3. กด `ดูช็อตเด็ด` เพื่อเช็กภาพ และติ๊ก **`ตัดช็อตเด็ดตอน Export`** เมื่อต้องการใช้งาน |

### แท็บที่ 2: `Transform` (จัดกรอบภาพ, สปีด และสโลว์เนียน)

| เครื่องมือ | หน้าที่การทำงาน | วิธีใช้งานแนะนำ |
| :--- | :--- | :--- |
| **Transform & Orientation** | ซูม (`Zoom X/Y`), ขยับตำแหน่ง (`Position X/Y`), หมุน `90° / 180° / 270°`, กลับซ้าย-ขวา (`Flip`) และโหมด `Fit / Fill / Stretch` | ใช้ `Fill` เมื่อต้องการครอปแนวนอนให้เต็มจอ `9:16` |
| **Cropping** | ตัดขอบ ซ้าย / ขวา / บน / ล่าง แบบละเอียด | ใช้เก็บขอบไมค์หรือขอบสิ่งกีดขวาง |
| **Speed Change + AI Smooth** *(ใหม่ v2.4.0)* | ปรับความเร็ว `25%–400%` (ซิงก์เสียง `atempo` อัตโนมัติ) พร้อมปุ่มเพิ่มเฟรมเรต **`30fps | 50fps | 60fps | 120fps`** | - คลิป `25fps` สโลว์ `50%` → กด **`50fps`**<br>- คลิป `30fps` สโลว์ `50%` → กด **`60fps`**<br>- กดซ้ำที่ปุ่มเดิมเพื่อยกเลิก (กรอบสีน้ำเงินหาย) |
| **Stabilization** | ลดอาการสั่นไหวของคลิป | เปิดใช้เฉพาะคลิปที่ถือมือเปล่าแล้วสั่นมาก |

### แท็บที่ 3: `Color` (แต่งสีระดับโปร + AI Filter Studio)

- **Scopes + EXIF กล้อง 12+ แบรนด์ & Codec:** ดูกราฟ `RGB / Luma / Parade / Vector` และข้อมูลกล้อง/เลนส์/Codec ใต้กราฟ
- **AI Filter Studio:** 6 Pro LUT Looks (`Korean Clean`, `Tokyo Film`, `Sport Crisp`, `Golden Hour`, `Forest Trail`), **AI Color Match** (ดูดสีจากรูปต้นแบบเป็น `.cube` 3D LUT), และ **Pro Skin Glow & Smooth** (`Fast` / `Face AI (เว้นตา/บิบ)`)
- **White Balance:** `As Shot | Daylight | Cloudy | Shade | Tungsten` + `Temperature / Tint`
- **Basic & Tone + Smart Tone (AI Face):** ปุ่มกดเปิด/กดซ้ำยกเลิก (`Natural / Pro` + `Batch Auto`) + สไลเดอร์ครบชุด (`Exposure` ถึง `Saturation`)
- **ColorSlice (7-Vector):** แยกปรับ 7 ช่วงสีแบบ DaVinci Resolve
- **Noise Reduction:** ลดนอยส์ Spatial / Temporal สำหรับคลิปแสงน้อย

### แท็บที่ 4: `Deliver` (ตั้งค่าไฟล์ส่งออก)

- **Video:** `1080×1920` / `2160×3840`, บิตเรต, Codec (`H.264 / H.265 / ProRes`), Multi-Worker
- **Audio:** `AAC / PCM / Copy` + ซิงก์เสียง `atempo` อัตโนมัติ
- **File:** ตั้งรูปแบบชื่อไฟล์, โฟลเดอร์ย่อย, และ `Skip / Overwrite`

### AI Video Face Search (แถบด้านบน)
- เลือกรูปใบหน้า 1 รูป + โฟลเดอร์วิดีโอ → สแกนหาทุกคลิปที่มีคนนั้นด้วย **AuraFace-v1 CoreML** แบบออฟไลน์ 100%

## 4. สูตรตั้งค่าด่วนสำหรับงานจริง (Quick Cheat Sheet)

| ประเภทงาน | สูตรแนะนำใน ZCut PRO |
| :--- | :--- |
| **งานวิ่งกลางแจ้ง / แดดจัด (100+ คลิป)** | `Edit`: คัดเบลอทั้งคลิป → `Color`: กด `Smart Tone (Natural)` + ติ๊ก `Batch Auto` + `AI Filter: Sport Crisp 50%` → `Deliver`: `1080×1920`, `H.264`, `12000k`, `3 Workers` |
| **งานเทรลในป่า / แสงร่มไม้** | `Color`: `Smart Tone (Natural)` + `AI Filter: Forest Trail 60%` + `Mask Mode: Face AI` (`Skin Smooth 25%`, `Face Glow 20%`) |
| **ช็อตเข้าเส้นชัยสโลว์เนียน (TikTok/Reels)** | `Edit`: `AI Highlight Cutter 4s` → `Transform`: `Speed 50%` + **`AI Smooth 50fps`** (จากคลิป 25fps) หรือ **`60fps`** (จากคลิป 30fps) |
| **คุมโทนสีให้เหมือนเรฟลูกค้า 100%** | `Color` → `AI Filter Studio` → `Pick Reference Photo` เลือกรูปเรฟลูกค้า → ปรับ `Intensity 65–80%` → กด Export ทั้งชุด |
